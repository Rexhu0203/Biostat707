# BIOSTAT 707 Checkpoint 1

This repository contains the BIOSTAT 707 Checkpoint 1 Jupyter notebook setup. Place the raw patient files in `data/set-a/` and place `Outcomes-a.txt` directly in `data/`. The project should eventually be run with `pixi run --locked checkpoint1`, which executes `checkpoint1.ipynb` and writes the rendered HTML and derived outputs under `output/`.
